流式思维链窗口：固定高度 + 永远停在最新一步

原型 · 对应 CopilotStreamingMessage 里的 ThoughtTimeline · 只改展示层，不动事件流
要解决的问题
  1. 现在 .thought-timeline 没有高度限制，步数一多气泡被无限拉长，答案被顶出视野
  2. 新步骤进来时，最新那条不保证可见（要靠整页滚动去追）
  3. 用户想回头看上文时，页面又被自动滚动抢走位置
方案：给思维链一个固定高度的内层窗口（默认 220px），新步骤进来时自动贴底； 用户一旦往上滚就暂停自动跟随，改用一个「N 条新思考 · 回到底部」的胶囊，点它再恢复。

落地要点（给实现用的清单）

项做法
.thought-bodyheight: 220px; overflow-y: auto; overscroll-behavior: contain（不用 max-height，避免"内容少时窗口塌下去"造成跳动）
跟随判定距底 ≤ 24px 视为"在底部"；scroll 事件里实时更新，不由定时器轮询
新步骤处理贴底状态 → 直接 scrollTop = scrollHeight；非贴底 → 只累加未读数并显示胶囊
胶囊「↓ N 条新思考」，点击后滚到底并把未读清零、恢复跟随
折叠状态头部可折叠；折叠期间不滚（省一次 layout），展开时一次贴底
结束本轮停止跟随动画，头部变为「已完成 · N 步 · 用时 1:42」，窗口保持原位不跳
动效新步骤 slidein 260ms；prefers-reduced-motion 下全部关闭
移动端窗口高度降到 160px，胶囊固定在窗口底部内缘
