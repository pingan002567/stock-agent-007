研究如何变成值班

白天你按漏斗把标的送进自选/持仓；收盘机器只读这个宇宙，写成简报。中间不断线，也不下单。

先认清两张台

L1 是人开的研究台：圈候选、体检、深研、进自选。L2 是半自动值班：15:15 收盘体检，只写简报，不交易。自选+持仓是中间那根线。

L1 研究台 · 人

入口对话空态 / 个股空态 动作圈候选 → 体检 → 深研 → 进自选 产物观察池、真仓、研究报告

L2 值班台 · 机器

入口收盘体检 每天 15:15 动作读持仓宇宙 → 落盘简报 产物今日简报、待办、失败推送
红线 execution_guard.auto_trade = false · 值班权限封顶 A3 · 禁止自动下单

不再丢一句「你想问什么」。四步芯片就是研究路径：点哪一步，Copilot 就按哪一步干活。

2. 体检：每个数字带来源

盈利、负债、PE/PB 相对位置。拉不到就写「未验证」，不编。体检过关的，才配进深研。

3. 深研：必须看市场结构

投资论点、三情景、正反论据。A 股可以谈抛压/套牢；港股/美股禁止写获利或套牢比例——没有 CYQ 就不要装有。

4. 进自选：线在这里交给晚上

结论站得住，才提醒你加入观察池，并写一句该盯什么。不自动下单。自选+持仓，就是 L2 值班的全部宇宙。

15:15 收盘体检：机器接手同一宇宙

默认开启。Copilot 只做研究、必须拉快照/事件/待办。系统在跑完后自己落盘值班简报，不指望模型去点「生成报告」。

任务周期上次
盘前简报每天 08:30成功
收盘体检每天 15:15成功报告
周度复盘每周日 17:00未运行 · 默认关
权限封顶 A3 · 提示词禁止 generate_report · 简报类型 ops_briefing

休市就跳过，不写假简报

盘前/收盘跟 A 股日历：周末和国庆不跑。周度周日仍跑。任务页显示「已跳过 / 今日休市」。立即运行不受日历限制，方便你补看。

周日 周度复盘

日历不跟 A 股休市 产物仍进报告库

宇宙大于 15 只：只深拉 Top 8

持仓按权重大、再拼自选。超过 15 只时，简报只展开 Top 8，其余一行涨跌。值班不会被名单撑爆，也不会假装逐只深研过。

亮的 8 只 = 深拉 · 暗的 = 一行带过 · 简报里会写「共 N 只，仅深拉 Top 8」

失败不断线：待办 + IM

Copilot 跑崩，仍然落一张降级简报，例外进复核箱。失败推到已有 IM 通道，和盯盘告警同一个出口。你早上看总览就能看见。
