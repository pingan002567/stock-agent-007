# 功能页面规划 + UI 设计规范

> 2026-07-17 沉淀。前置:三栏布局(左会话/中聊天/右功能坞)、Editorial Calm 设计语言
> (doc/design/TEAMCLAW_UI_ALIGNMENT.md)、技能编排预算模型(doc/SKILL_ROADMAP.md 2026-07 节)。

## 一、总原则

聊天是唯一的"动作入口",右栏功能页退居两种角色:

- **看板**:只读速览,提供聊天流没有的信息密度(表格、时间线、分组);
- **档案库**:结构化浏览历史产物(报告、回测、事件)。

页面内的"生成/扫描/草案"类按钮逐步退化为**带预填问题开聊天**的快捷方式,
避免与 AI 工具链形成第二套操作路径(与配置双源同病)。

## 三、UI 设计规范(功能坞页面)

### 3.1 基线(沿用,不新造)

- **色彩**:Editorial Calm 四层纸色 `--background #fbfaf7 → --paper → --panel → --selected`,
  墨色四层 `--foreground → --ink-2 → --muted → --faint`;
- **强调色预算**:每屏蓝色 ≤2 处(主操作/激活态);绿/红只留给涨跌与告警级别,
  功能页里不得挪作装饰;
- **字体**:PingFang SC 栈;所有数字 `tabular-nums` + mono(`.num`);
- **卡片**:一律竖排单列(`page-stack`,既定决策),14px 圆角 paper 卡,卡内字段网格保持横排。

### 3.2 面板统一解剖(所有功能页共享)

```
┌─ func-head(40px,拖拽区)────────────────┐
│ 页面标题                    [问 AI] [✕] │
├─ page-kpi(可选,一行 3-5 个小指标)──────┤
│ 市值 ¥1.2M   当日 +0.8%   高优告警 2    │
├─ page-stack(滚动区,竖排卡片)───────────┤
│ ┌ SectionCard ───────────────────────┐ │
│ │ 标题          [badge]    [问 AI ↗] │ │
│ │ 表格 / 时间线 / 字段网格            │ │
│ └────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

- **func-head**:已有;右侧固定两枚 ghost 图标钮:「问 AI」(带当前页上下文开聊)、「收起」。
- **page-kpi**:新原语。11px `--faint` 标签 + 15px mono 数值,横排 flex,无边框无底色
  (数字本身就是视觉层次,不加卡片噪音)。涨跌数值用绿/红,其余用 `--foreground`。
- **SectionCard**:复用设置页原语(标题/描述/右侧 mono badge),功能页与设置页同一套解剖。

### 3.3 通用原语(新增 4 个,放 components/ui/)

| 原语 | 规格 | 用于 |
|---|---|---|
| `PageKpiRow` | 见 3.2;点击项=带预填问题开聊 | 总览/持仓/盯盘头部 |
| `DataTable` | 紧凑表:行高 32px,表头 11px `--faint` 大写,数字列右对齐 mono,hover 行 `--selected` 底,行尾 hover 显操作(TeamClaw 卡片解剖同款) | 持仓/自选/策略列表 |
| `StatusDot` | 6px 圆点+11px 文案:绿=正常/通过,红=告警/未通过,琥珀=进行中,灰=暂停 | 盯盘规则/任务/报告门禁 |
| `AskAiButton` | ghost 小钮「问 AI ↗」:携带 {page, symbol?, 预填 prompt} 调 useCopilotChat 开新聊/追问;蓝色仅 hover 态出现(守强调色预算) | 所有卡片头/表格行尾 |

### 3.4 逐页 UI 蓝图

- **总览**:PageKpiRow(市值/当日/告警/待审) → 指数条(原 Market,横排 4-5 个 mono 涨跌) →
  「高优告警」卡(StatusDot 列表,≤5 行,行点击跳盯盘) → 「最近报告」卡(3 行,点击跳报告)。
  全页零表单零按钮,唯一交互=跳转与问 AI。
- **个股档案**:头部 = symbol + 名称 + 现价涨跌(大号 mono)+ AskAiButton;
  卡序:AI 观点(评分/立场/置信,来自 ai_state) → 财务摘要(季/年切换 pill) →
  情报时间线(11px 时间戳 `--faint` 左栏 + 内容右栏) → 历史报告列表。
  锚点跟随:会话 symbol 变化 → 本页自动刷新目标(仅当本页已打开,不抢焦点)。
- **自选**:分组用 `--faint` 大写小标题分节(同左栏会话分组),组内 DataTable
  (代码/名称/现价/涨跌/操作);拖拽排序保留,行尾 hover:上移/下移/删除/问 AI。
- **持仓**:PageKpiRow(市值/成本/盈亏/集中度) → DataTable(持仓主表,权重列带 4px
  细进度条,超限行左缘 2px 红条) → 「风险结论」卡(最近一次扫描结果只读,含时间戳,
  底部 AskAiButton「重新评估」=发话到聊天)。
- **盯盘(告警中心)**:PageKpiRow(高优/今日事件/规则数) → 「待处理」卡
  (severity 分组,行=StatusDot+摘要+时间,展开=根因+建议动作+问 AI) →
  「规则」卡(DataTable:规则/状态 ToggleSwitch/冷却) → 「推送通道」卡(现企微配置)。
- **策略**:DataTable(策略/状态/最近回测/操作) → 点行右侧滑入回测详情
  (复用 DetailBody 工具卡组件,同一份回测渲染) → 「纸上交易」卡(市值/现金/持仓数字段网格)。
- **报告**:筛选行(类型 pill + symbol 输入,唯一表单) → 列表卡:标题/StatusDot 门禁/
  时间/导出图标(语音/PPT);点行=右栏内正文预览(Markdown,同聊天气泡渲染器)。
- **任务**:仅「定时/后台」两组 StatusDot 列表;行=名称+下次触发时间(mono)+最近结果;
  若最终并入盯盘,则为其一个 SectionCard。

### 3.5 状态规范

- **加载**:骨架屏统一用现 `PanelSkeleton/KpiSkeleton`,禁止 spinner 满屏;
- **空态**:图标(1.5px 线性,`--faint`)+ 一句话 + 可选 AskAiButton(如自选空态
  「让 AI 帮你找几只候选」),复用左栏会话空态解剖;
- **错误**:卡内 `ErrorMessage` 原语,不弹 toast(toast 只留给动作反馈);
- **刷新**:无手动刷新按钮(既定决策),数据随 lastRefreshTime 静默更新,
  func-head 标题右可挂 11px `--faint` 「刚刚/3 分钟前」。
