Stock Agent 首页改版 · 设计计划与原型

按 frontend-design 的流程：先定 token 与版式 → 对照"通用默认"自评 → 再出图。改动只在呈现层。
一、设计计划（先定，再画）

色彩 · 6 个命名色

paper #FBFAF7 ink #14181C rule #E2DED4 accent #1F5C55 up #C0352B down #2E7D5B
为什么不用
奶油底 #F4F1EA + 陶土红 #D97757 —— 这是当下最典型的"AI 生成感"，而且和 A 股红涨冲突。
为什么用墨青
红绿已被盈亏语义占满，结构强调必须退出这套语义，否则"强调"和"涨"分不清。
纸面偏暖
因为它承载的是"交割单 / 研报 / 晨报"这类纸面物件，不是 SaaS 后台。

字体 · 三种角色，不是三种性格

结论/标题
宋体（Songti SC）。研报、公告、晨报的印刷语汇——这是本产品的"母语"，不是装饰。
正文/界面
系统黑体 PingFang SC，1.75 行高，行宽 ≤ 78 字。
数字
等宽 + tabular numerals，只用于表格与金额；不用它做小标签（那是模板感来源之一）。
字号阶梯
10.5 / 11.5 / 12.5 / 13 / 19 / 27（只有头条用 27）

左对齐。所有金额右对齐、等宽、同一行基线。
分层方式
用线、缩进、字号，不用卡片阴影。阴影只留给真正浮起的层（弹窗、浮层）。

五条原则

  • 1语义色不可挪用：红绿只表示涨跌与盈亏，结构强调一律用墨青。
  • 2一张纸，不是一堆卡：取消卡片网格与统一阴影，靠线与留白分层。
  • 3数字优先：金额/比例等宽右对齐，单位做小字后缀，不重复写"元/股"。
  • 4每天只有一个头条：结论一句话最大，其余信息降到 12–13px。
  • 5按中文排版：1.75 行高、行宽 ≤78 字、数字与中文之间留 1/4 空隙、标点不占行首。

自评（对照"通用默认"）

初版我准备做：大数字 + 三张 KPI 卡 + 渐变强调 + 每个区块 fade-up —— 这换成任何一个 dashboard 都成立，属于 skill 明确点名的默认解。
改版后：用晨报头条替代 KPI 卡组，用账本线替代卡片网格， 把"响亮"只花在头条一处，其余全部安静；动效只保留"数字更新时的一次跳动"，不做入场动画。
二、原型对比：现状 vs 新方向
现状：卡片 + 阴影 + 统一圆角 新方向：一张纸 + 账本线 + 宋体头条

三、具体改什么（都是呈现层，不动信息架构）
元素现在改成判断
品牌 eyebrow空状态/首页顶部一行大写 "STOCK AGENT"删掉；品牌只出现在报头一行宋体字里删
KPI 卡片组3 张同圆角同阴影的卡合并成头条右侧三个数字，用竖线分隔删
模块容器每块一张卡片（圆角 12 + 阴影）取消卡片；用 1px 线与缩进分层，阴影只留弹窗删
统计串中点号"思考 3 步 · 调用 3 个工具 · 1 分 10 秒"保留（是统计语义，不是装饰）；只清理纯装饰性串联留
等宽小标签大量小标签用等宽只在表格数字与代码用等宽；标签改回黑体收
入场动效页面每块 fade-up、卡片 hover 位移不做入场；只在数字变化时跳一次，hover 只给可点击行收
圆角6/8/10/12 + 999 混用收敛三档：4（表格/线框）、6（按钮）、12（弹窗）收
表格数字部分左对齐、部分等宽统一右对齐 + tabular numerals + 单位小字后缀留
四、边界与不做什么
不动：信息架构、路由、三栏骨架、A 股红涨绿跌语义、表格密度、键盘流、宠物浮层。
不做：换全套字体文件（用系统宋体/黑体，零加载成本）、改暗色主题的整体色相、加装饰性渐变或插图。
验收：同一屏信息量下，扫读时间更短、数字更好比、结论一眼可见；深色模式对比度不降级。
